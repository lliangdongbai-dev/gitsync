🚀 GitSync 部署手册

单机部署 — 前端 + 后端 + 数据库一体化运行

架构说明

GitSync 是单进程一体化应用，前端构建后的静态文件由后端 Express 直接托管。

部署时只需启动一个 Node.js 进程，它同时提供：

  • 📄 前端页面（静态文件，来自 client/dist/）
  • 🔌 后端 API（/api/* 路由）
  • 📡 SSE 实时推送（/api/events）
  • 💾 SQLite 数据库（data/gitsync.db）

💡 不需要分别部署前端和后端，也不需要 Nginx 做前端托管。一个端口搞定一切。

一、Docker Compose 部署（推荐）

前置要求

  • Docker 20.10+
  • Docker Compose v2+

部署步骤

# 1. 上传项目到服务器（或 git clone）
git clone <your-repo-url> /opt/gitsync
cd /opt/gitsync

# 2. 创建环境变量文件
cp .env.example .env

# 3. 编辑配置
vim .env

# 4. 一键构建并启动（前端+后端自动构建打包）
docker compose up -d --build

# 5. 查看日志确认启动成功
docker compose logs -f

Docker 构建过程（自动完成）：

  1. Stage 1：构建前端 → npm run build → 生成 client/dist/
  2. Stage 2：构建后端 → npm run build → 生成 server/dist/
  3. Stage 3：运行时 → 将两者合并，安装 git，启动 Node.js

最终容器内结构：

/app/
├── dist/           # 后端编译产物
├── client/dist/    # 前端编译产物（由后端静态托管）
├── data/           # 数据目录（持久化）
│   ├── gitsync.db  # 数据库
│   ├── repos/      # bare repo 缓存
│   └── ssh_keys/   # SSH 私钥
└── node_modules/   # 生产依赖

环境变量说明

变量默认值说明
PORT3001服务端口（前端+API 共用）
AUTH_USER空访问认证用户名（留空不启用）
AUTH_PASS空访问认证密码
ENCRYPTION_KEY空Token 加密密钥（32位字符串）
LOG_RETENTION_DAYS7同步日志保留天数
DB_PATHdata/gitsync.db数据库文件路径
REPO_DIRdata/reposbare repo 缓存目录
SSH_KEY_DIRdata/ssh_keysSSH 私钥目录

SSH Key 配置

# 将私钥复制到容器
docker cp ~/.ssh/id_rsa gitsync:/app/data/ssh_keys/id_rsa

# 设置权限（必须为 600）
docker exec gitsync chmod 600 /app/data/ssh_keys/id_rsa

访问服务

部署完成后浏览器访问：http://<服务器IP>:3001

前端页面和后端 API 都在这一个端口上。

二、Node.js 直接部署（无 Docker）

前置要求

  • Node.js 20+（node -v 确认）
  • npm 9+
  • Git 2.30+（git --version 确认）

完整部署步骤

# 1. 上传项目到服务器
git clone <your-repo-url> /opt/gitsync
cd /opt/gitsync

# 2. 构建前端（生成 client/dist/）
cd /opt/gitsync/client
npm ci
npm run build

# 3. 构建后端（生成 server/dist/）
cd /opt/gitsync/server
npm ci
npm run build

# 4. 配置环境变量
cd /opt/gitsync
cp .env.example server/.env
vim server/.env

# 5. 直接启动（测试用）
cd /opt/gitsync/server
node dist/index.js
💡 后端启动后会自动托管 client/dist/ 目录的前端文件。
访问 http://IP:3001 即可看到完整的前端界面 + API。

使用 PM2 守护进程（生产推荐）

# 安装 PM2
npm install -g pm2

# 使用项目自带的配置启动
cd /opt/gitsync
pm2 start ecosystem.config.js

# 查看状态
pm2 status

# 查看日志
pm2 logs gitsync

# 设置开机自启
pm2 startup
pm2 save

PM2 ecosystem.config.js 说明：

  • 工作目录：./server
  • 入口文件：dist/index.js（编译后的后端）
  • 自动重启、内存超 512M 自动重启

三、反向代理（可选）

如果需要域名访问或 HTTPS，在前面加一层反向代理：

Nginx 配置

server {
    listen 80;
    server_name gitsync.example.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name gitsync.example.com;

    ssl_certificate /etc/nginx/ssl/cert.pem;
    ssl_certificate_key /etc/nginx/ssl/key.pem;

    # 所有请求都转发到 Node.js（前端+API 都在 3001）
    location / {
        proxy_pass http://127.0.0.1:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # SSE 实时推送需要关闭缓冲
    location /api/events {
        proxy_pass http://127.0.0.1:3001;
        proxy_set_header Host $host;
        proxy_set_header Connection '';
        proxy_http_version 1.1;
        chunked_transfer_encoding off;
        proxy_buffering off;
        proxy_cache off;
    }
}

Caddy 配置（自动 HTTPS）

gitsync.example.com {
    reverse_proxy localhost:3001
}
💡 Caddy 自动申请和续期 Let's Encrypt 证书，零配置 HTTPS。

四、安全配置

生产环境必做清单

  1. ✅ 设置 AUTH_USER + AUTH_PASS 启用访问认证
  2. ✅ 设置 ENCRYPTION_KEY 加密存储的 Token
  3. ✅ 使用 HTTPS（反向代理 + SSL 证书）
  4. ✅ 防火墙只开放 80/443，不直接暴露 3001 端口
  5. ✅ SSH 私钥权限设为 600

生成加密密钥

# 生成 32 位随机密钥
openssl rand -hex 16
# 输出类似：a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6

五、备份与恢复

备份

所有数据都在 data/ 目录下，备份这个目录即可：

# Docker 环境
docker cp gitsync:/app/data ./backup-$(date +%Y%m%d)

# 直接部署
cp -r /opt/gitsync/server/data ./backup-$(date +%Y%m%d)

数据目录结构：

文件/目录说明是否必须备份
data/gitsync.dbSQLite 数据库（任务、日志、设置）✅ 必须
data/ssh_keys/SSH 私钥文件✅ 必须
data/repos/本地 bare repo 缓存❌ 可选（会自动重建）

恢复

# Docker 环境
docker compose down
docker cp ./backup-20260523/. gitsync:/app/data/
docker compose up -d

# 直接部署
pm2 stop gitsync
cp -r ./backup-20260523/* /opt/gitsync/server/data/
pm2 start gitsync

九、一键部署脚本

适用于全新的 Linux 服务器（需要 root 权限）：

#!/bin/bash
# GitSync 一键部署脚本
set -e

# 安装 Docker（如果未安装）
if ! command -v docker &> /dev/null; then
    echo "正在安装 Docker..."
    curl -fsSL https://get.docker.com | sh
    systemctl enable docker
    systemctl start docker
fi

# 克隆项目
git clone <your-repo-url> /opt/gitsync
cd /opt/gitsync

# 生成安全配置
ENCRYPTION_KEY=$(openssl rand -hex 16)
AUTH_PASS=$(openssl rand -base64 12)

cat > .env << EOF
AUTH_USER=admin
AUTH_PASS=$AUTH_PASS
ENCRYPTION_KEY=$ENCRYPTION_KEY
LOG_RETENTION_DAYS=30
EOF

# 构建并启动
docker compose up -d --build

# 输出信息
SERVER_IP=$(hostname -I | awk '{print $1}')
echo ""
echo "======================================"
echo "  GitSync 部署完成！"
echo "======================================"
echo "  访问地址: http://$SERVER_IP:3001"
echo "  用户名:   admin"
echo "  密码:     $AUTH_PASS"
echo "  加密密钥: $ENCRYPTION_KEY"
echo "======================================"
echo "  配置文件: /opt/gitsync/.env"
echo "  数据目录: Docker volume (gitsync-data)"
echo "======================================"
