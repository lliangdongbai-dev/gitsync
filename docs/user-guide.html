快速开始

创建同步任务

  1. 进入「任务列表」页面，点击「新建任务」
  2. 填写任务名称（如：生产环境代码同步）
  3. 配置源仓库 URL 和认证方式（HTTPS Token 或 SSH Key）
  4. 配置目标仓库 URL 和认证方式
  5. 选择同步范围（所有分支+标签 / 自定义选择）
  6. 设置同步频率（如每5分钟、每小时）
  7. 点击「创建任务」完成

同步范围配置

模式说明
所有分支 + 标签完整镜像，同步源仓库的全部分支和标签
仅所有分支只同步分支，不同步标签
仅所有标签只同步标签，不同步分支
自定义选择手动选择要同步的特定分支和标签

自定义选择模式

  • 切换到「自定义选择」后，系统自动从源仓库获取分支和标签列表
  • 支持多选、搜索过滤、全选/清空快捷操作
  • 也可以手动输入分支/标签名称（即使获取列表失败）
  • 点击「获取远程分支」按钮可随时刷新列表

认证配置

HTTPS Token

适用于 HTTPS 格式的仓库 URL（如 https://github.com/user/repo.git）

平台Token 获取方式
GitHubSettings → Developer settings → Personal access tokens
GitLabSettings → Access Tokens
Gitee设置 → 私人令牌
Token 需要有仓库的读写权限（repo scope）。

SSH Key

适用于 SSH 格式的仓库 URL（如 git@github.com:user/repo.git）

填写 SSH 私钥文件名或绝对路径，系统按以下顺序查找：

  1. data/ssh_keys/<文件名>（应用目录）
  2. ~/.ssh/<文件名>（用户 home 目录）

通知配置

通知策略

默认行为：仅同步失败时发送通知

在「系统设置」中可开启「同步成功时也发送通知」开关，开启后成功和失败都会通知。

同步日志

进入「同步日志」页面查看历史记录：

  • 支持按任务、状态筛选
  • 点击任意一行展开查看详情：

详情内容：

  • 🌿 每个分支同步的 commit 数（如 dev: 3 commits、master: 0 commits）
  • 🏷️ 标签同步状态（新增/已存在）
  • 📊 同步模式和总 commit 数

任务卡片信息

每个任务卡片显示以下信息：

  • 任务名称和运行状态
  • 源仓库 → 目标仓库（含认证方式图标）
  • 同步频率（如「每5分钟」）
  • 同步范围摘要（如「2个分支 + 3个标签」）
  • 上次同步时间
  • 下次同步倒计时（仅运行中的任务显示）
  • 错误信息（如有）

访问认证

在「系统设置」中可配置 Basic Auth 保护：

  • 设置用户名和密码后，访问页面和 API 都需要认证
  • 留空则不启用认证
⚠️ 生产环境强烈建议启用认证并配合 HTTPS 使用。

常见问题

Q: 修改了同步频率后需要重启任务吗？

A: 不需要。保存任务后系统会自动更新定时计划。

Q: 源仓库和目标仓库可以用不同的认证方式吗？

A: 可以。源仓库和目标仓库的认证是完全独立配置的。

Q: 同步会覆盖目标仓库的内容吗？

A: 是的。同步使用 --force 推送，目标仓库的对应分支会被源仓库完全覆盖。请确保目标仓库仅用于镜像。

Q: 删除任务会清理本地缓存吗？

A: 会。删除任务时会自动清理本地的 bare repo 缓存目录。

Q: 同步失败后任务会停止吗？

A: 不会。任务状态会变为「异常」，但定时计划仍然有效，下次触发时会重新尝试同步。
